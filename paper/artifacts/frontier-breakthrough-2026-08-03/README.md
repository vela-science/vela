# Frontier breakthrough campaign baseline

This directory freezes the source and repository identities used to select the
next Vela campaign. It is research-control evidence, not scientific Standing.

`baseline.v1.json` records the exact local Git heads, released Vela binary,
Harbor version, retained Astra source identity, and rooted Erdős source files.
`candidate-screen.v1.json` records the preliminary scientific work selection.
`erdos-647-discovery-plan.v1.json` freezes the scientific question, inherited
negative state, success and nonclaim rules, wall-clock execution envelope, and
Decision boundary. It remains a draft until the exact model, Harbor task,
machine, verifier bytes, and final plan root are recorded before model output.
`source-campaign-inventory.v1.json` separates merged Formal Conjectures source,
fork and pull-request candidates, the curated `lean-proofs` solved shelf, and
exploratory campaign branches. `MANIFEST.sha256` binds all JSON artifacts
exactly.

The screen is intentionally asymmetric:

- Erdős 203 is the primary new-discovery prospect because one finite
  two-dimensional cover would settle the retained existential problem, the
  exact merged Formal Conjectures statement is pinned, and the corrected
  exploratory campaign exposes a concrete structured-search route;
- Erdős 647 is the fixed witness reserve because one finite witness would
  settle its existential problem and admit a small exact verifier;
- Erdős 7 is the fixed construction reserve because one explicit odd distinct
  covering system admits exhaustive finite verification modulo its least
  common multiple;
- Erdős 264 is the qualifying real correction and repair case, but receives no
  novelty credit; and
- Astra's ten advances are the external-release inheritance case, not Vela
  discoveries.

The existing Erdős 647 plan remains reserve evidence; it is not the selected
primary plan. The final Erdős 203 discovery task must add a literature cutoff, exact task packet,
verifier, budget, retry rule, and plan root before any model output. This
baseline does not authorize a scientific Decision or claim that Erdős 203 will
be solved.
