# Product-compression v3

This directory retains the compact result of the corrected native Harbor
confirmation study. The study compares two fresh Git/files inspections with two
fresh Vela-guided inspections of the same frozen Erdős campaign and pending
Decision.

The two Vela-guided sessions produced the exact frozen answer. Neither Git/files
session did. Vela-guided reduced median agent time by 51.61 percent, median cost
by 60.37 percent, uncached-token proxy by 58.84 percent, and tool calls by 28.57
percent. The pre-registered composite nevertheless failed because it required
every session—including the control arm—to be exact and every session to stay
below a 24,000 cumulative observed-token budget; neither condition held.

That registered failure is immutable. The source benchmark now records a
prospective methodology correction rather than rerunning or relabeling this
study: execution integrity and bounded retained outputs are hard eligibility
gates; exactness is compared between arms; actual cost and elapsed time decide
efficiency; tool calls and provider token counters remain telemetry. Under that
interpretation this run is strong task-specific product-comprehension evidence,
not a retroactive registered pass.

The generated Harbor job cache was removed after the compact result bound its
full sorted-file root, frozen plan, fixture, answer key, task set, exact
toolchain, all four trial roots, failures, and stopped predecessor plan.
Verification was offline, authority was unavailable, and no Frontier or
scientific Standing changed.

This result is first-party evidence on one bounded comprehension task. It is not
external adoption or a general claim that Vela improves scientific output.
