# External cold-reader pilot

This directory freezes the smallest external study that can test Vela's
current product-comprehension claim without adding another harness or changing
scientific Standing.

Four readers external to Vela will each inspect two different fixtures. One
fixture is shown through the root-bound Observatory and the other through Git
plus the same evidence. Task and interface order are counterbalanced. Each
reader sees each scientific fixture only once.

The fixtures are:

- the accepted Quantum `[[10,1,4]]` correction; and
- the accepted Formal cross-Frontier retention Claim.

The study asks whether readers can identify the exact Claim, evidence,
Verification scope, Decision and Standing, nonclaims, and next valid action.
It does not ask them to judge the science or perform a Decision.

## Boundary

This is a product-reading pilot. It is not independent scientific
verification. The Observatory is a disposable read-only projection, Git
Frontiers remain canonical, Verification is not acceptance, and participants
receive no credentials or mutation controls.

The frozen held-out correction selector still has no qualifying consequential
topology. Even a positive pilot cannot satisfy the full registered B10
protocol-breakthrough gate.

## Frozen files

- `plan.v1.json` fixes participants, counterbalancing, surfaces, prompts,
  scoring, timing, exclusions, stop rules, the positive gate, and publication
  policy.
- `answer-key.v1.json` fixes the semantic answers and hard authority errors
  before participant one.
- `operator-guide.v1.md` freezes the neutral glossary, clock semantics, timeout
  handling, and non-coaching procedure.
- `response-form.v1.json` freezes the de-identified answer and timing fields.
- `amendment.v1.json` root-links the frozen plan to the exact current public
  Observatory deployment before participant one, records the answer-key
  revalidation, and adds a fail-closed manifest preflight without changing the
  study method.
- `manifest.sha256` binds the five study-control files.

Eligible failures, timeouts, and null results are retained. No favorable
stopping, fixture substitution, or post-output scoring change is allowed.

Earlier frozen plans were superseded before participant one: first after the
human repository authority accepted the Formal Proposal, then to correct one
Quantum applied-event identifier and remove operator/scoring discretion. No
participant had enrolled or viewed evidence. The current plan root-links its
predecessor; Git retains the earlier bytes.

The plan's original Observatory deployment was then superseded before
participant one. `amendment.v1.json` preserves the plan and answer key byte for
byte while binding execution to the current public deployment and requiring an
exact public-manifest preflight before every participant. Any deployment or
projection drift stops the study; it is not repaired after participant one.

## Remaining execution

Recruit four eligible readers, record de-identified responses and timings,
score each response independently twice, adjudicate disagreements, and publish
the compact result with its exact artifact manifest. No code, service,
database, model call, or additional Vela component is required.
