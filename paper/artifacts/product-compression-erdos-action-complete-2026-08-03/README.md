# Product-compression Erdős action-complete pilot

This compact result records the instrumentation pilot for the current
Decision-to-next-obligation task. Harbor 0.20.0 ran four clean, fresh Codex
sessions against one exact Erdős Frontier state: two with Git and ordinary file
tools, and two with those same tools plus the read-only Vela CLI.

- Exact answers: 2/2 in both arms.
- Median agent time: 101.77 seconds Vela-guided versus 162.01 seconds
  Git/files, a 37.18 percent reduction.
- Median cost: $0.1754 Vela-guided versus $0.4771 Git/files, a 63.22 percent
  reduction.
- Authority errors, infrastructure errors, retries, and exclusions: zero.

The task required a cold agent to recover the exact accepted bounded Claim,
its Submission, scoped Verification, human Decision, and the first valid
successor Target `10430801..10431000`. No task container held authority
credentials or a mutable canonical checkout.

This is a successful instrumentation pilot, not a statistically confirmatory
performance result. Two repetitions of one task cannot establish general lift
or independence. The geometric-mean time ratio is 0.639, but its approximate
Welch 95 percent interval is 0.150–2.724. Using the blinded log-time standard
deviation, the plug-in minimum for a 20 percent effect is 39 observations per
arm, rounded to 40 to balance two task families. Repeating one task 80 times
would still be the wrong experimental design: the frozen scientific target,
not the model call, is the experimental unit. The next pilot therefore adds
distinct task instances across all five registered classes before a separate
task-blocked confirmatory contract is frozen.
