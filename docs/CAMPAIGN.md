## The one result this campaign must produce

The campaign is successful only if it produces one legible chain:

```text
important source state
-> exact unresolved obligation
-> bounded native-agent campaign
-> novel or corrective scientific artifact
-> independent scoped check
-> attributed human Decision
-> replayed Standing
-> exact next obligation
-> successful cold-successor continuation
```

The scientific artifact may be a new theorem, counterexample, exact witness,
meaningful strengthening, or externally useful correction. A clean null result
is valid campaign evidence, but it is not a breakthrough.

The campaign is not successful merely because:

- a model writes a persuasive proof;
- Lean accepts a theorem whose informal statement has not been checked;
- a bounded search finds nothing;
- ten public repositories compile;
- a graph becomes larger;
- a repeated-call benchmark reports a small p-value; or
- Vela records more objects.

## Product boundary

Vela owns:

```text
exact source and state binding
bounded work contract
authenticated Submission
scoped Verification
attributed Decision
deterministic Event and Standing replay
correction and inheritance consequences
```

Native systems own:

```text
Codex or another agent       research execution
Harbor                       isolation, trials, and evaluation artifacts
Lean and Comparator          formal checking
domain programs and solvers  bounded computation
Git                          canonical Frontier custody
RO-Crate 1.3                 derived research-object transfer
```

The Observatory and Atlas remain root-bound, read-only projections. No model,
rank, graph, verifier, database, or benchmark may change Standing.

Decision packets and read projections should explain the existing state through
four derived routes rather than new protocol objects: exact source, native
transformation or check, scientific reasoning and uncertainty, and attributed
authority. Informational receipts stay outside the Decision queue. A cold
reviewer should see the semantic Standing diff, affected and surviving routes,
unreviewed gaps, and the exact next obligation without reconstructing them from
raw records.

Measure that compression directly: time to decisive source, time to reconstruct
the producer transformation, errors distinguishing Verification from Decision,
precision and recall of affected and surviving correction routes, and cold
successor time to the next exact obligation. Count reviewer judgment separately
from context reconstruction. Object, graph, and agent-call volume are not
success metrics.

### D. Cumulative inheritance benchmark

The benchmark unit is a unique scientific episode, not a model call.

Every paired block must bind a unique:

The matched arms receive identical scientific facts, model, tools, compute,

The minimum confirmatory design has:

- at least two scientific task families;

Instrumentation pilots and case studies may use fewer blocks but must set
`claim_credit: false`.

## Success metrics

### Primary outcomes

| Outcome | Operational definition | Success threshold |
| --- | --- | --- |
| Scientific advance | A claim absent at the frozen literature cutoff, bound to an exact artifact, passing a distinct native verifier and expert scope review | At least one; otherwise report an honest null |
| Authority-correct exact pass@1 | Fraction of all assigned attempts that are exact and make no Standing/authority error | Guided arm noninferior within the registered 10-point margin; zero authority errors |
| Restricted time-to-exact | Exact attempts use measured agent time; inexact attempts receive the full deadline | Point ratio at most 0.80 and upper 95% confidence bound below 1; reserve “confirmed 20%” for an upper bound at most 0.80 |
| Correction fidelity | Exact affected routes, surviving routes, invalid evidence, and repair obligation | 100% affected-set precision and recall, 100% surviving-route recall, zero stale-state use |
| Cold inheritance | A different producer reaches the exact next valid obligation and passes its native verifier without private predecessor state | Exact on the real correction and discovery successor, or fail transparently |

### Secondary outcomes

- cost per assigned attempt and per exact pass;
- expert minutes to find decisive evidence and make the Decision;
- cold-review errors in locating the authority boundary, correction blast
  radius, and next valid obligation;
- duplicate work and repeated certified failure;
- number and class of failed routes retained;
- clean-clone reproduction rate;
- source-to-check, check-to-Decision, and Decision-to-remap latency;
- exact downstream reuse; and
- disagreement and correction comprehension time.

Do not optimize or headline graph size, object count, agent calls, raw token
volume, or accepted-Claim count.

### Hard guardrails

No positive result survives:

- an unauthorized Standing transition;
- Verification presented as acceptance;
- answer leakage or post-output target selection;
- hidden failed runs or success-conditioned cost reporting;
- stale source or root drift;
- a source claim presented as community consensus;
- a formal theorem whose informal fidelity is unresolved but omitted;
- pooled lift when a task family reverses direction; or
- repeated calls on one lineage cluster counted as independent science.

## Stop and pivot conditions

Stop the affected lane on:

- source or repository root drift;
- ambiguous statement fidelity;
- answer leakage;
- verifier dependence on the producing agent's hidden state;
- unbounded compute without an information-gain checkpoint;
- unauthorized or automatic scientific Decision;
- a projection becoming hidden authority;
- an external framework becoming necessary for replay;
- a benchmark that cannot distinguish repeated calls from independent
  episodes; or
- a proposed subsystem that native tools plus a thin adapter can replace.

If the discovery campaign fails, retain the negative routes and exact next
obligation, then evaluate whether Vela improved the successor's work. If the
matched study ties flat state, keep Vela as scientific-state and authority
