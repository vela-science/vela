# Lean Correspondence + Foundry empirical program

Status: **method frozen; execution forbidden**.

This directory preregisters the method for the next Lean Correspondence
evaluation and a later read-only Foundry consumption demonstration. It contains
no participant response, selected held-out family, protected answer, permit,
provider event, score, Vela object, Repository write, Decision, or Standing
change.

The sequence is deliberately gated:

1. Stage A runs an open, non-confirmatory pilot on the two already visible
   calibration packets and one deliberately invalid relation.
2. Only a passing Stage A permits an independent source selector to freeze six
   unseen families from at least three independently versioned Lean
   repositories.
3. Stage B compares raw-source review with correspondence-assisted review. A
   structured-but-unwitnessed control is included only if its atom-equivalence
   audit proves that it isolates witness/inheritance lift.
4. Stage C specifies a derived, read-only Foundry packet and Browser QA. It is
   not implemented here.
5. Stage D binds claims to evidence and defines the paper and kill criteria.

The prior 36-cell study is retained as a negative result at the exact roots in
`evidence-bindings.json`. Its Git/documents 12/12, neutral wrapper 12/12, and
Vela 11/12 result, including one authority error and all positive gates false,
is neither rerun nor reinterpreted.

## What is frozen

- `study-contract.json`: stages, participants, denominators, estimands, gates,
  stop lines, and the required later prelaunch bindings.
- `response.schema.json`: one closed participant response.
- `foundry-packet.schema.json`: the future derived display packet.
- `evidence-bindings.json`: exact current Vela, maintained qualifier, reviewed
  Lean Correspondence, calibration, real-correction, plural-authority, Web, and
  prior-negative-result bindings.
- `PROTOCOL.md`: operational method and custody boundaries.
- `PROMPT.md`: the exact common task prompt, arm preambles, and substitution
  rules.
- `PAPER_PLAN.md`: evidence/claim matrix, paper outline, bundle inventory, and
  kill criteria.
- `scoring-fixtures.json`: public no-science fixtures for Decimal arithmetic.
- `verify.py` and `test_verify.py`: deterministic artifact verification and
  fail-closed mutation tests.

## Verify the frozen method

```bash
uv run --project conformance --locked python \
  paper/artifacts/lean-correspondence-foundry-study/verify.py

uv run --project conformance --locked python -m unittest discover \
  -s paper/artifacts/lean-correspondence-foundry-study -p 'test_*.py'
```

The verifier checks the complete material inventory, exact Git bindings that
are locally available, closed schemas, fixed denominator arithmetic, selection
and custody stop lines, Decimal-only scoring fixtures, equality-as-failure,
and the absence of selected held-out families or protected material.

Before any future pilot or confirmatory permit is released, a separate
prelaunch artifact must bind the exact runner, participant configurations,
assignment seed commitment, selected source commits/trees/blobs, atom-
equivalence receipts, adjudication commitment, and the receipt emitted by the
maintained qualifier at `tools/evidence_qualification/qualification.py`. This
directory does not copy that machinery and does not satisfy that gate.
