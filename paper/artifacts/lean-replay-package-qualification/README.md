# Historical Lean replay package qualification

> Historical evidence (2026-08-17). This failed Level 0 experiment does not
> define current Vela behavior and has no live consumer.

This directory retains the result of a source-local Lean replay package
experiment. The package implementation is no longer in the tree. It failed its
net-deletion gate, and both named consumers were archived read-only. Git history
retains the implementation; `qualification.json` retains the evidence and the
stop condition that prevented promotion.

The record is not a package index, Registry, Vela object, Verification Record,
or source of scientific authority. Its historical roots and old repository
commits are reproducibility facts only. A future extraction would have to earn
the consumer, net-deletion, and cross-platform gates again against live
repositories under the then-current contract.
