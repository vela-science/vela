## `vela-readme-hero.jpg`

Generated with OpenAI's built-in image-generation tool on 2026-08-20 for the
Vela README. SHA-256:
`51f43d4d5db878a6dc39bf0e1171a956c650610b17837a6925100b3ee00fc028`.

Final prompt:

> Create a polished wide 2:1 editorial hero illustration for the open-source
> project Vela. The concept is scientific inheritance: a single modern sailing
> vessel at sea at blue hour, navigating by a sparse constellation whose
> connected stars subtly resemble a branching map of accumulated scientific
> results. Behind the vessel, one precise luminous wake remains visible as a
> retained, correctable route; ahead, the horizon opens into unexplored dark
> blue space. Visual language: refined contemporary scientific editorial
> illustration, restrained watercolor washes combined with crisp ink and
> subtle screenprint texture, deep midnight navy, cobalt, sea-glass teal, warm
> parchment, and one small cinnabar accent. Strong simple silhouette, generous
> negative space, calm confidence, sophisticated enough for a leading
> open-source GitHub README. Emphasize one big idea, not a process diagram. No
> machinery, no UI panels, no boxes, no arrows, no pseudo-text, no words, no
> logo, no labels, no fantasy steampunk, no busy infographic, no glowing
> portal. Accessible contrast in both GitHub light and dark surroundings;
> important content centered with safe margins for a 960px-wide README image.

The image is atmospheric editorial art. It is not evidence, a scientific map,
a protocol record, or a representation of current Standing.

## `vela-system-map.html` and `vela-system-map.svg`

The README system map uses the sources-to-core-to-consumers integration grammar
from [diagram-design](https://github.com/cathrynlavery/diagram-design). Its
seven-node ceiling keeps the explanatory architecture separate from the full
Protocol 1 object model.

The HTML file is the editable source of truth. The SVG is the first inline SVG
extracted byte-for-byte from that source for GitHub README rendering. Colors
and typography use the current Vela Web product tokens: paper, ink, water,
cinnabar, Geist, and Geist Mono.
