# Three-arm identification design

The sealed predecessor study cannot identify whether its observed differences
come from structured current-state presentation or from Vela's distinct
authority-scoped Decision, Standing, and inherited-repair semantics. StateMem
is relevant primary-source evidence that structured persistent state can itself
improve long-horizon agent work, so Git/documents versus Vela alone is not an
adequate decomposition for a flagship governance claim. See StateMem,
arXiv:2608.19652v1, <https://arxiv.org/abs/2608.19652>.

This prospective artifact therefore has three matched arms:

- Git/documents is the unstructured same-information baseline.
- State-wrapper provides explicit predecessor/successor, dependencies,
  active/superseded/needs-recheck/current views, and neutral scope and
  acceptance facts. It has no Vela, Repository, Decision, Event, Standing, or
  replay vocabulary or mechanism.
- Vela organizes the same facts using the previously qualified projection and
  authority-scoped inherited-repair presentation.

Every family/arm packet is generated from the same atomic family object and
contains byte-identical source and evidence members. Presentation may change
organization only. The maximum serialized prompt is prospectively bounded at
1.20 times the minimum within each family.

The family-balanced additive estimands are structure lift (state-wrapper minus
Git/documents), governance/inheritance lift (Vela minus state-wrapper), and
total lift (Vela minus Git/documents). Exact-success and correction-impact
completion rates use treatment-minus-control improvement; authority-error rate
uses control-minus-treatment reduction; restricted time uses
control-minus-treatment savings, with time ratios secondary. Equal cell counts
also permit transparent count deltas. The total
Vela-versus-Git gate is preserved. The structure gate is proportionate. The
governance gate requires family noninferiority and a strict aggregate
increment; equality alone cannot support governance lift.

The three unseen families prospectively vary the authority regime: no
acceptance action, an independently authorized acceptance action, and a
referenced action whose authorization is presently unprovable. The result, if
the study is later authorized and run, is a bounded descriptive gate over these
synthetic cases rather than a broad significance or scientific-acceptance
claim.
