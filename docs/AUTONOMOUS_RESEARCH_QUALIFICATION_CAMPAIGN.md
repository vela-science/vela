# Autonomous-research qualification campaign

## Objective

Test whether exact Vela scientific state improves the correctness and
inheritability of native autonomous-research work without turning Vela into an
agent runner or treating repeated calls as independent science.

## Entry gates

Do not begin confirmatory work until:

- the Result Dossier product gate passes;
- at least two case implementations reuse the projection machinery;
- Erdős 730 and Astra expose stable source/fidelity packets;
- one fresh-discovery verifier is frozen before model output; and
- a real external reviewer is available for the confirmatory protocol.

## Phase 0 — instrument the loop

Run `claim_credit: false` exercises only:

```text
Target -> native agent/harness -> Submission -> scoped Verification
-> human Decision/deferral -> replay -> next obligation
```

Use one formal-mathematics case and one process-verifiable environment. Preserve
all failures, retries, infrastructure incidents, model/tool versions, costs,
and shared dependencies. Confirm that audited, assisted, and governed modes
remain distinct and that no agent receives authority credentials.

Produce four read-only products from exact state where useful:

- Result Dossier;
- Research Trajectory;
- Inheritance Packet; and
- Evaluation Incident View.

These are projections, not protocol objects.

## Phase 1 — confirmatory comparison

Only after Phase 0 passes, preregister forty paired scientific episodes across
two task families: KernelBench-Verified or an equivalent process-verifiable
environment, and formal mathematics using Formal Conjectures/native Lean.
Episode and lineage roots—not calls—are the units.

Require:

- information-matched flat and Vela-guided arms;
- case-blocked randomization and a producer/model swap;
- exact task success and statement fidelity;
- zero authority errors;
- retained failure and correction routes;
- cold-successor recovery of the next valid obligation; and
- independent external review of the registered sample.

## Claims

Phase 0 supports only instrumentation and feasibility statements. Phase 1 may
support the preregistered bounded comparison if the full sample and uncertainty
gates pass. It cannot establish general autonomous-science capability,
adoption, or universal productivity.

## Adapter boundary

Autoresearch, KernelBench, Formal Conjectures, and other harness adapters remain
source-local and read/write only through existing authenticated Submission and
Verification commands. No adapter may decide, change Standing, or become a
Vela scheduler.
